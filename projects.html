P.02

Q# RAG Chatbot

University of Arizona Innovation Award, 2025

A retrieval augmented chatbot that indexes Q# documentation and feeds matching context into a Mistral-7B model running on llama-cpp. React front end, Node back end, PostgreSQL underneath. I built it in a VIP class and it won a University of Arizona Innovation Award.

React · Node.js
Mistral-7B · llama-cpp
PostgreSQL
